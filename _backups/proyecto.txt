Resumen del proyecto:
	- El trabajo analiza el sistema actual de Crisnamart y propone mejoras orientadas a la digitalización del negocio.
	- Como primer paso implementable, se desarrollará una landing page institucional con dominio propio, que redirija al catálogo de Jazz Nube y permita la comunicación directa por WhatsApp.
	- Se consideran además etapas futuras con mayor automatización, aunque implicarían costos adicionales o reprocesos hasta poder integrarse plenamente con el sistema de integración con Jazz Gestión.


Análisis de los problemas:
	1. Problemas Operativos →  La ausencia de definición formal de roles genera superposición de tareas y dependencia de la gestión diaria para mantener la operación con clientes y proveedores.

	2. Problemas Tecnológicos → El sistema de gestión se utiliza parcialmente, con errores de carga acumulados, convivencia con registros manuales, dificultando trazabilidad y toma de decisiones de largo plazo en base a datos.

	3. Problemas Comerciales → La empresa carece de una presencia digital atractiva y de herramientas para comunicar promociones o novedades de forma masiva, dependiendo casi por completo del contacto individual con cada cliente.


Objetivo del proyecto:
	- Mejorar la gestión y visibilidad de Crisnamart mediante soluciones digitales iniciales que faciliten la comunicación con clientes y la administración de información, sentando las bases para futuras mejoras tecnológicas y comerciales


Propuestas de implementación:
	1. Landing page institucional
	2. Catálogo dinámico mediante CSV público
	3. Sistema de pedidos en PDF con base de datos externa
	4. E-commerce completo integrado con stock y facturación

Propuesta #1 – Landing page institucional:
	- Página estática sin usuarios, catálogo ni carrito.
	- Información de la empresa, ubicación, contacto, horarios.
	- Redirección a e-commerce de Jazz Nube.
	- Ventajas: 
		- Implementación inmediata
		- Mayor presencial digital
		- Coste minimo
		- No requiere mantenimiento
	- Desventajas: 
		- No resuelve el problema del ecommerce de JazzNube.
	- Costo: 
		-$8.500 anual (dominio .com.ar y hosting gratuito).

Propuesta #2 – Sitio web (sin integración a Jazz-Gestión).
	- Base de datos para registro de clientes y administradores.
	- Usuario "cliente" crea su propia cuenta, agrega items de catálogo a carrito de compra y genera pedidos.
	- Usuario "administrador" actualiza catálogo y promociones.
	- Pedidos exportables como PDF o segun convenencia para su armado. 
	- Script para exportar productos con stock real desde base de datos de JazzGestion hacia sitio web.
	- Ventajas: 
		- Mejor experiencia para el cliente.
		- Libertad de crear promociones y catálogos.
		- Permite comenzar a escalar hacia un sistema robusto.
	- Desventajas: 
		- Mayor coste de mantenimiento (implica contratar un servidor y mantener el sitio)
		- Requiere vendedor que actualize el catálogo e ingrese los pedidos en JazzGestion para reduccion de stock y facturación.
	- Costo: 
		-$65.000 mensual (cubre costes de dominio, servidor, base de datos, actualizaciones y mantenimiento)

Propuesta #3 – E-commerce completo y paulatina integración o reemplazo de Jazz-Gestión.
	- Todo lo anterior + registro de pedidos, sincronizacion de stock, facturacion, pagos por plataforma, cuentas corrientas.
	- Aplicacion de escritorio 
	- Integración parcial con Jazz o reemplazo completo del sistema utilizando base de datos existente.
	- Ventaja: 
	- Limitación: alto costo y complejidad, requiere mantenimiento profesional
	- Ventajas:
		-Creacion de un sistema completamente adaptado a las necesidades del negocio.
		- Sitio web profesional a la altura de los ecomerces modernos.
		- Facilitaria la gestión de inventario, productos,
		- Permite generar datos estadisticos para la toma de decisiones.
		- Mismo costo de mantenimiento que la propuesta anterior.
	-Desventajas:
		- Alto costo de implementación y más lenta: requiere diseñar todo de cero. visitas presenciales o copia de la base de datos. 
	- Costo: 
		-$65.000 mensual por lo anterior + coste de implementacion segun horas trabajadas.

Implementacion actual:
	- Se desarrolló una landing page institucional moderna utilizando Blazor WebAssembly.
	- El sitio presenta una interfaz adaptable, con secciones de inicio, catálogo de productos, texto institucional y formulario de contacto.
	- Incluye accesos a comunicación directa con WhatsApp
	- Permite incorporar un catálogo visual con productos cargados localmente. 
	- La aplicación funciona de manera estática y offline, pudiendo alojarse sin costo en plataformas como Netlify o GitHub Pages.

Posibles mejoras:
	- Catálogo dinámico mediante archivo CSV:
		- Permitiría actualizar los productos directamente desde el sistema actual mediante un archivo exportado.Requiere un servidor con API y base de datos liviana (por ejemplo, MySQL o SQLite) para almacenar información de productos, categorías e imágenes.Costo estimado: aprox. $8.000 – $12.000 anuales (hosting + mantenimiento básico).
	- Sistema de pedidos con base de datos externa o envío directo:
		- Los clientes podrían generar pedidos online y recibir un PDF estructurado listo para su carga manual en Jazz Gestión.Puede implementarse sin servidor ni base de datos (enviando los formularios directamente por correo o WhatsApp), aunque sin validaciones ni persistencia.Costo estimado: $0, o el mismo que el punto anterior si se utiliza la base de datos del catálogo.
	- E-commerce completo integrado con stock y facturación:
		-Permitiría registrar clientes, actualizar stock en tiempo real y generar comprobantes automáticos.Requiere integración directa con la base de datos de Jazz Gestión y soporte técnico especializado.Costo estimado: variable según alcance (implementación avanzada + mantenimiento mensual).
